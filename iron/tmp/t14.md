**Т14 разбор задач t12-t13**

- проверять реквизиты Справочников на Р→Свойства→Использование(для элемента/для группы/&то&др) иначе программный обход может завершиться неочивидной ошибкой(!)
- ДополнительныеСвойства()

    <details>
    <summary>пример</summary>

  ```
  проверить новый элемент или нет, по пустой ссылке ПередЗаписью(), добавив результат в ДополнительныеСвойства() и ПриЗаписи() использовать свойство:
  ```

  ```js
  // Модуль Справочник.Контрагенты
  Процедура ПередЗапсью(Отказ)
  ЭтоНовый = Ссылка.Пустая();
  ДополнительныеСвойства.Вставить("ЭтоНовый",ЭтоНовый);
  КонецПроцедуры

  Процедура ПриЗаписи(Отказ)
  Если ДополнительныеСвойства.ЭтоНовый Тогда
  //создать договор
  НовыйДоговор = Справочники.ДоговорыКонтрагентов.СоздатьЭлемент();
  НовыйДоговор.Владелец = Ссылка;
  НовыйДоговор.Номер = "1";
  НовыйДоговор.ДатаДоговора = ТекущаяДата();
  НовыйДоговор.Наименование = "Основной договор";

  Если Покупатель Тогда
    НовыйДоговор.ВидДоговора = Перечисления.ВидыДоговоров.СПокупателем;
  ИначеЕсли Поставщик Тогда
    НовыйДоговор.ВидДоговора = Перечисления.ВидыДоговоров.СПоставщиком;
  ИначеЕсли ПрочиеОтношения Тогда
    НовыйДоговор.ВидДоговора = Перечисления.ВидыДоговоров.Прочее;
  КонецЕсли

  НовыйДоговор.Записать();

  КонецПроцедуры

  ```

    </details>

- оптимизация запросов (выз.сервера, контекст.форм)

  <details>
  <summary>пример</summary>

  ![form][def_form]

  ```js
  &НаКлиенте
    Процедура ПриАктивизацииСтроки(Элемент)

      ТекКонтрагент = Элементы.Список.ТекущаяСтрока;
      Контакты = ПолучитьКонтрагенты(ТекущаяСтрока);

      ЮрАдрес = Контакты.ЮрАдрес;
      ФактАдрес = Контакты.ФактАдрес;
      Телефон = Контакты.Телефон;
      ЭлПочта = Контакты.ЭлПочта;

    КонецПроцедуры

  &НаСервереБезКонтекста
    Функция ПолучитьКонтрагенты(Контрагент)

      КонтрагентОбъект = Корнтагент.ПолучитьОбъект();

      СтруктураДанных = Новый Структура("ЮрАдрес","ФактАдрес","Телефон","ЭлПочта");

      Для каждого СтрокаКИ Из КонтрагентОбъект.КонтактнаяИнформация Цикл
        Если СтрокаКИ = Справочники.ВидыКонтактнойИнформации.ЮридическийАдресКонтагента Тогда
          СтруктураДанных.ЮрАдрес = СтрокаКИ.Значение;
        ИначеЕсли СтрокаКИ = Справочники.ВидыКонтактнойИнформации.ФактическийАдресКонтагента Тогда
          СтруктураДанных.ФактАдрес = СтрокаКИ.Значение;
        ИначеЕсли СтрокаКИ = Справочники.ВидыКонтактнойИнформации.ТелефонКонтагента Тогда
          СтруктураДанных.Телефон = СтрокаКИ.Значение;
        ИначеЕсли СтрокаКИ = Справочники.ВидыКонтактнойИнформации.ЭлектроннаяПочтаКонтагента Тогда
          СтруктураДанных.ЭлПочта = СтрокаКИ.Значение;
        КонецЕсли;

        Возврат СтруктураДанных;

    КонецФункции
  ```

  </details>
